# Ворота (gate-vision) — интеграция Home Assistant

<p align="center">
  <img src="custom_components/gate_vision/brand/icon.png" width="120" alt="gate-vision">
</p>

**Определение состояния подъёмных ворот по камере** — без магнитов, герконов и меток.
Интеграция смотрит кадр камеры, которая видит полотно ворот, и говорит **ЗАКРЫТО / ОТКРЫТО**.
Внутри — веб-панель с редактором зон, порогами, реагированиями и журналом.

| Параметр | Значение |
|:---|:---|
| Домен | `gate_vision` |
| Версия | 1.1.0 |
| Тип | `hub`, `local_polling` |
| Зависимости | нет (numpy/Pillow уже есть в HA) |
| Минимум HA | 2025.1 |

## Запреты по сенсорам (interlocks)

Правило запрета блокирует выбранные команды, пока выполнено условие на сенсоре Home Assistant.
Пример: «уличная температура меньше −25 °C → запретить **закрытие**».

* **Сенсор** — любая сущность HA (`sensor.*`, `binary_sensor.*`, …), при необходимости — **атрибут** сущности.
* **Условие:** больше / меньше / равно / не равно / включён / выключен (для `binary_sensor`, `input_boolean`, «открыто/закрыто»).
* **Команды:** открыть / закрыть / стоп / импульс (расписание). Ничего не отмечено → правило действует на все команды.
* **Режим:** `запрещать` (команда отклоняется, запись в журнал и событие `gate_vision_interlock`) или `только предупреждать` (команда выполняется, но событие и предупреждение в журнале пишутся).
* **Недоступный сенсор запретом не считается** — иначе управление «встанет» при потере связи (в журнал пишется debug-запись).
* Правила живут с каждой камерой (записью интеграции): вкладка **«Запреты»** в панели; API `GET/POST /api/gate_vision/interlocks`.

## Возможности

- **Сущность `binary_sensor` с `device_class: garage_door`** — открыто/закрыто, готово для автоматизаций, дашборда и голосового ассистента.
- **Работает днём и ночью.** Днём «открыто» видно по светлой улице под полотном; ночью камера уходит в ИК — правило зеркальное, а окна полотна читаются как тёмные ячейки на подсвеченном полотне.
- **Зоны детекции.** Можно указать, где искать признак «открыто» (низ проёма), где «закрыто» (окна полотна) и что игнорировать (тележка, столб, край кадра).
- **Веб-панель «Ворота»** в боковом меню: живой кадр, рисование зон мышью, пороги с моментальным применением, журнал событий.
- **Реагирования на события**: открылись, закрылись, оставлены открытыми, движение полотна, состояние не определяется, камера недоступна/вернулась.
  Каналы: push (`notify.*`), уведомление в HA, озвучка (TTS), скрипт/служба, MQTT, webhook. Плюс повтор и тихие часы.
- **Диагностика**: режим кадра (день/ИК), яркость зон, движение полотна, доступность камеры, текст решения детектора.
- **Управление (опционально, по умолчанию выключено)**: `cover` с импульсным реле, памятью направления, ожиданием подтверждения по камере и запретом команд при неизвестном состоянии.

## Установка

### HACS (как custom repository)
1. HACS → Интеграции → ⋮ → «Добавить пользовательский репозиторий» → URL репозитория, тип «Integration».
2. Установить «Ворота (gate-vision)», перезапустить Home Assistant.
3. Настройки → Устройства и службы → «Добавить интеграцию» → **Ворота (gate-vision)**.

### Вручную
Скопировать `custom_components/gate_vision` в `<config>/custom_components/` и перезапустить HA.

## Настройка

В мастере добавления:

| Поле | Описание |
|:---|:---|
| **Название** | как будет называться устройство |
| **Кадр** | RTSP-адрес камеры, имя потока go2rtc или готовый URL снапшота |
| **Адрес go2rtc** | по умолчанию `http://127.0.0.1:1984` |
| **Интервал опроса** | секунды (по умолчанию 5) |

Кадр можно взять тремя способами:

```
rtsp://admin:PASS@192.168.4.200:9784/cameras/6/streaming/main   # RTSP напрямую
Ворота                                                          # имя потока в go2rtc
http://127.0.0.1:1984/api/frame.jpeg?src=...                    # готовый URL
```

> Совет: чтобы не дёргать камеру ad-hoc запросами, добавьте поток в `go2rtc.yaml`
> (`Ворота: rtsp://...`) и укажите в интеграции просто его имя.

## Панель «Ворота»

Открывается из бокового меню HA.

**Зоны.** Рисуются мышью прямо по кадру:

| Роль | Что это | Признак |
|:---|:---|:---|
| 🟩 **Закрыто (окна)** | область окон полотна | подтверждает «закрыто» |
| 🟧 **Открыто (низ проёма)** | где появляется улица при подъёме полотна | **основной признак** |
| ⬜ **Исключение** | помехи (тележка, столб, край кадра) | исключается из расчёта |

ЛКМ по пустому месту — нарисовать зону, тянуть — сдвинуть, за уголок — изменить размер.
Кнопка «Зоны по умолчанию» возвращает проверенную геометрию.

**Пороги.** День: зона «открыто» светлее порога → ОТКРЫТО. Ночь/ИК: темнее порога → ОТКРЫТО.
Применяются сразу, без перезагрузки.

**Реагирования.** Для каждого события — включение, каналы, получатели, текст, повтор, тихие часы.

**Управление.** Включается отдельно, когда известен номер реле ворот. Пока выключено —
сущность `cover` не создаётся, интеграция только читает состояние.

## Сущности

| Сущность | Тип | Что показывает |
|:---|:---|:---|
| `binary_sensor.<имя>` | `garage_door` | **открыто / закрыто** (главная) |
| `binary_sensor.<имя>_gate_leaf_moving` | `moving` | полотно движется |
| `binary_sensor.<имя>_camera` | `connectivity` | камера отвечает |
| `sensor.<имя>_frame_mode` | — | режим кадра: день / ночь-ИК |
| `sensor.<имя>_zone_open_brightness` | — | яркость зоны «открыто» |
| `sensor.<имя>_zone_closed_brightness` | — | яркость зоны «закрыто» |
| `sensor.<имя>_open_seconds` | `duration` | сколько ворот открыты |
| `sensor.<имя>_last_change` | `timestamp` | когда состояние изменилось |
| `sensor.<имя>_last_event` | — | последнее событие |
| `sensor.<имя>_detector_decision` | — | текстовое решение детектора |
| `cover.<имя>` | `garage` | управление (только если включено) |

Атрибуты главного сенсора: `state`, `raw_state`, `reason`, `mode`, `moving`, `stale`,
`camera_ok`, `b_open`, `b_closed`, `windows`, `changed_at`, `open_since`, `open_seconds`, `left_open`.

## События

Интеграция шлёт на шину HA событие `gate_vision_state_changed`:

```yaml
event: opened | closed | left_open | moving | unknown | camera_lost | camera_back
state: closed | open | unknown
reason: "ч/б (ИК): зона «открыто» тёмная (32 < 60) — видна улица"
ts: "2026-09-16T10:52:28+00:00"
```

Пример автоматизации (свет в гараже при открытии):

```yaml
trigger:
  - platform: event
    event_type: gate_vision_state_changed
    event_data:
      event: opened
action:
  - service: light.turn_on
    target:
      entity_id: light.garage
```

## HTTP API

Все запросы требуют авторизации в HA (Bearer-токен).

| Метод | Путь | Назначение |
|:---|:---|:---|
| GET | `/api/gate_vision/frame?fresh=1` | последний кадр (JPEG) |
| GET | `/api/gate_vision/state` | состояние + анализ + настройки + журнал |
| GET | `/api/gate_vision/settings` | текущие настройки |
| POST | `/api/gate_vision/settings` | изменить зоны/пороги/реагирования/управление |
| POST | `/api/gate_vision/test` | принудительная проверка кадра |
| GET | `/api/gate_vision/events?limit=50` | журнал событий |

## Как это работает

1. Интеграция получает кадр (по умолчанию через go2rtc), с повторами — go2rtc иногда отвечает 500 на «холодном» старте.
2. Считает профиль яркости по строкам в плоскости ворот и измеряет яркость зон.
3. **День (цветной кадр):** низ проёма светлее порога → ОТКРЫТО, иначе ЗАКРЫТО.
   **Ночь/ИК (ч/б):** низ проёма темнее порога → ОТКРЫТО, иначе ЗАКРЫТО.
4. Дополнительно ищет полосу окон (яркая зона, зажатая тёмным полотном) — подтверждение «закрыто».
5. Короткие провалы «неизвестно» сглаживаются (держит последнее состояние), движение полотна определяется по разнице профилей.
6. Смена состояния и события уходят в шину HA и в настроенные каналы реагирования.

Логика проверена на реальных данных: 4196 замеров за сутки, у закрытых ворот яркость низа проёма
60–140, у открытых 140–220, **в зоне неоднозначности 135–145 — ни одного замера**.

## Ограничения

- Нужна камера, которая **видит полотно ворот** (снаружи или изнутри).
- Если камера уходит в ИК и улица тоже тёмная, признак «открыто» опирается на контраст полотна; при полной темноте возможен статус «неизвестно».
- Управление (`cover`) требует известного номера реле и по умолчанию выключено.
